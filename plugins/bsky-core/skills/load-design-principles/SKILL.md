# Load Design Principles

Use tag-as-index, not semantic recall alone.

1. List collective-conscious entries in the design-principle scope or category.
2. Filter by explicit tags and metadata relevant to the task, while retaining global principles.
3. Read every matching principle in full.
4. Deduplicate and note conflicts, precedence, and applicability.
5. Carry the resulting set into the invoking work and cite principle names when they affect a decision.

If collective-conscious is unavailable, say so and continue with repository instructions and local design evidence. Never invent a principle from memory.

Provider seam: the completeness algorithm is core craft; collective-conscious names, scopes, tags, and tools are the current house provider and may be replaced by another indexed principle store.
