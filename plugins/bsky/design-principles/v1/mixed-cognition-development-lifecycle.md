# Mixed-Cognition Development Lifecycle

The unit of progress is not "a human wrote code with AI assistance." It is:

> **A mixed-cognition team advanced a claim with receipts.**

A plausible lifecycle:

`charter -> claims/invariants -> independent inquiry -> executable model/prototype -> adversarial falsification -> decision+dissent -> implementation atoms -> independent review -> conformance/proof -> deployment receipt -> observed operation -> revision`

Constructs supply breadth, parallelism, implementation, exhaustive variation, and durable trace. Humans supply stakes, meaning, causal judgment, consent, taste, and the ability to notice that everyone is confidently solving the wrong problem.

Neither group supervises the other by default. **The workflow supervises all participants.**
